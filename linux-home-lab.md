# Linux Home Lab

This page documents my Linux learning journey through hands-on practice in Ubuntu, including lessons, concepts learned, terminal commands, labs, and reflections.
## Linux Security Lab 1: Incident Investigation ✅

### Objective
Create and organize a simulated incident investigation using the Linux command line.

### Tasks Completed
- Created an investigation directory
- Organized evidence, notes, screenshots, and report folders
- Created evidence files
- Edited files using `nano`
- Viewed file contents using `cat`
- Verified the investigation structure using `ls` and `pwd`

### Evidence Collected
- `browser-history.txt`
- `downloads.log`
- `suspicious-file.txt`

### Investigation Summary
Reviewed browser history, download history, and a suspicious file. Identified `freegift.ru` as the suspicious website, `free_game.exe` as the most suspicious download, and connected the evidence to a possible malware infection.

### Commands Practiced
- `cd`
- `pwd`
- `ls`
- `mkdir`
- `touch`
- `nano`
- `cat`
- `rm`

### Reflection
This lab reinforced Linux navigation while introducing a realistic cybersecurity workflow. Instead of practicing isolated commands, I used Linux to organize evidence and perform a basic incident investigation, which made the commands much more meaningful.
